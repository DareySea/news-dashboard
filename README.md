# Дашборд редактора новостей

Мониторинг новостных сайтов, сайтов госорганов, Telegram- и MAX-каналов по рабочим областям, отчёты к нужному времени, календарь (работа + праздники РБК) и прямой эфир ТВ.

## Запуск на своём компьютере (Windows)

Нужен Node.js 22+. Двойной щелчок по `start.bat` или:

```
npm install
node server.js
```

Откроется http://localhost:3000. Пароль не спрашивается.

## Сервер 24/7

1. Арендовать сервер Ubuntu 22.04/24.04 в России (1–2 vCPU, 2 ГБ памяти) и домен (у многих хостингов есть бесплатный технический домен).
2. На сервере от root:

   ```
   git clone https://github.com/DareySea/news-dashboard.git /tmp/nd
   bash /tmp/nd/deploy/setup.sh <домен>
   ```

3. Открыть `https://<домен>`, логин любой, пароль: `sudo cat /etc/dashboard.env`.
4. Перенести данные с компьютера (области, новости, календарь): скопировать `data.json` и папку `reports` в `/opt/dashboard/app/` и выполнить `systemctl restart dashboard`.
5. Для MAX: в области с каналами MAX нажать «Войти в MAX» и отсканировать QR-код телефоном.

Обновление сервера до последней версии с GitHub: `bash /opt/dashboard/app/deploy/update.sh`.

## Что не хранится в репозитории

`data.json` (области, новости, календарь, адрес Google Календаря), `reports/`, `max-profile/` (вход в MAX) — это личные данные, они живут только на компьютере и сервере.
